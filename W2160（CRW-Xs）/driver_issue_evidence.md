# CH340 / HL-340 串口线硬件缺陷与 Windows 11 驱动兼容性排查报告

## 1. 设备与环境背景
* **涉事线材**：商家标题宣传为 `CH340G`，实物为 `HL-340` 廉价黑胶/克隆芯片 USB 转串口线。
* **硬件标识**：`USB\VID_1A86&PID_7523`
* **操作系统**：Windows 11 x64
* **系统自动安装驱动**：`4.0.2026.2` / `3.9.2024.9`（微软 WHQL 认证的最新官方南京沁恒驱动，驱动文件 `CH341S64.SYS`）

---

## 2. 故障现象与底层错误分析

在使用标准串口工具（如串口助手、.NET `System.IO.Ports.SerialPort`、Python `pyserial` 等）打开该设备所分配的 COM 端口（如 `COM6`）时，程序直接崩溃或抛出异常：

```text
System.IO.IOException: A device attached to the system is not functioning. (连到系统上的设备没有发挥作用)
Win32 Error Code: 31 (0x8007001F - ERROR_GEN_FAILURE)
```

### 底层 Win32 API 追踪细节
通过 Python ctypes 调用 Windows 原生 `kernel32.dll` 进行单步 API 隔离抓包：
1. `CreateFileW("\\\\.\\COM6", ...)` $\rightarrow$ **成功**（获得句柄 1000）
2. `SetupComm(...)` / `GetCommProperties(...)` $\rightarrow$ **成功**
3. `GetCommState(...)` $\rightarrow$ **成功**（读取当前默认参数: 9600, 8N1）
4. `SetCommState(...)` $\rightarrow$ **失败！返回 0，错误码 31 (`ERROR_GEN_FAILURE`)**

进一步隔离驱动 IOCTL：
* 发送 `IOCTL_SERIAL_SET_BAUD_RATE` 时，无论设置 9600 还是 115200，底层驱动向硬件端点下发 Vendor Control Transfer（寄存器配置指令）均发生超时或 STALL，驱动层直接返回 `STATUS_UNSUCCESSFUL`，向上抛出 Win32 31 错误。

## 3. 对照实验与责任界定

为了排除电脑主板 USB 口、系统设置、供电或外接读卡器模块干扰，设计了严密的对照实验：

| 对照组 | 测试条件 | 测试结果 | 结论 |
| :--- | :--- | :--- | :--- |
| **A. 拔除外设隔离** | 拔除读卡器，单插新买的 HL-340 线材直连电脑后置 USB 口 | 依然报错误 31 | 彻底排除读卡器短路/引脚拉死或供电过载原因 |
| **B. 相同环境对照** | 使用同一电脑、同一 USB 接口，插另一根配置路由器的原装串口线（同样识别为 COM 串口） | 秒开，9600 到 115200 所有波特率无一报错，双向数据收发顺畅 | 彻底排除电脑硬件、USB 端口及系统本身故障 |
| **C. 驱动降级实证** | 强制降级到商家提供的 **2011年版本驱动 (`3.3.2011.11`)** 后 | COM 端口恢复正常打开并能完成数据收发 | 证实芯片只能在旧版宽松指令下工作，无法兼容官方现代标准驱动 |

## 4. 行业内幕与技术根因

1. **正品 CH340G vs HL-340 山寨芯片**：
   * 正品南京沁恒 CH340G 芯片采用标准 SOIC-16 贴片封装，硬件寄存器完全符合原厂规范，在 Win10/Win11 自动安装的最新驱动下即插即用。
   * HL-340 往往采用廉价黑胶封装（COB）或第三方低成本克隆 ASIC，仅部分模拟了十多年前早期 CH340 的部分指令。
2. **官方驱动更新反克隆机制**：
   * 沁恒官方自 2022 年后重构了驱动架构（v3.8+ 及 2024/2026 的 v4.0），对时序、波特率分频寄存器及硬件校验更为严格。
   * 克隆芯片收到新版控制请求时无法响应，直接导致整个串口堆栈报废。
3. **Mac 平台不可用性**：
   * 现代 macOS（Apple Silicon M系列）全面采用 DriverKit 系统扩展，根本无法运行 2011 年的 32 位 legacy KEXT 驱动。HL-340 在现代 Mac 上属于完全死局。

## 5. 对线维权凭证模板

```text
【产品质量问题与虚假宣传反馈凭证】

设备型号：商家标题标注为 CH340G，实际为 HL340 山寨黑胶芯片线
硬件 ID：USB\VID_1A86&PID_7523
测试环境：Windows 11 x64 原生系统

【事实与证据】
1. 货不对板：标称正品 CH340G，实为无法运行现代标准驱动的 HL340 劣质芯片。
2. 底层通讯缺陷：在 Windows 11 微软认证驱动（CH341S64.SYS）下，调用标准波特率设置指令 SetCommState 时，硬件无法响应控制传输，持续抛出 Win32 Error 31 (连到系统上的设备没有发挥作用)。
3. 严格对照实验：
   - 同一台电脑、同一个 USB 接口，插入正规原装串口线，所有波特率全部秒通收发正常。
   - 必须强制降级至 2011 年 15 年前的远古老旧驱动才能勉强点亮，且一旦系统后台自动更新即刻瘫痪；在现代 macOS 上完全不可用。
证实该产品存在硬件批次缺陷或使用了缩水克隆芯片，属于质量问题与虚假宣传，请立即办理退换货。
```
